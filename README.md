## Features
- **All 14 Complete Lab Programs**: Full schema DDL, test data insertion, and all required exam queries.
- **Interactive AI Tutor (Professor Thangan)**: Built-in AI guidance for syntax breakdown, query explanation, oral viva simulation, and exam mistakes.
- **Full Responsive Design**: Optimized for smartphones (docked bottom navigation bar, touch switcher), tablets, and desktop displays.
- **Built-in SQL Practice Sandbox**: Test queries and practice typing SQL with instant feedback.
- **Oral Viva Preparation**: Dedicated flashcards and Q&A for every single lab experiment.
- **Zero API Key Requirement**: Works out-of-the-box with free AI tier and optional custom Google Gemini API key.

## Lab Curriculum
1. **A1**: Employee Table & Search Queries (LIKE, BETWEEN, DISTINCT, GROUP BY, HAVING)
2. **A2**: Client Table Surgery (CTAS, Structure Clone & DDL Alterations)
3. **A3**: Employee Record Updates & Transactions (DML Updates, COMMIT, ROLLBACK)
4. **A4**: Supplier-Part Relational Database (Composite Keys, Referential Integrity, Joins)
5. **A5**: Employee Hierarchy & Self Joins (Department aggregates & Subqueries)
6. **A6**: Student Academic Records & String Functions (Aggregations, Date & String manipulation)
7. **B1**: PL/SQL Multiplication Table Generator (WHILE loops, basic syntax)
8. **B2**: Factorial Calculation with Iterative Control (LOOP ... EXIT WHEN)
9. **B3**: Prime Number Verification & Divisibility (FOR loops, modulus arithmetic)
10. **B4**: String Manipulation & Palindrome Checker (Built-in string functions, conditional branches)
11. **B5**: Student Grade Evaluation System (Conditional IF-THEN-ELSIF logic)
12. **B6**: Bank Account Balance Management (Explicit Cursors, %NOTFOUND, %ROWCOUNT)
13. **B7**: Audit Trail Table Sync (Row-level Database Triggers, :NEW and :OLD audit log)
14. **B8**: Automatic Employee Salary Increment Engine (Cursor FOR loops, bulk updates)

## Deployment Options

### Option 1: Vercel (Recommended — 1 Click / GitHub)
1. Push this project to your GitHub account (`code-by-adi7`).
2. Go to [vercel.com](https://vercel.com) and log in with GitHub.
3. Click **"Add New..."** -> **"Project"**.
4. Select your repository and click **"Deploy"** (no build settings needed, it's 100% static!).
5. Your site is live on a custom `.vercel.app` domain with free SSL!

### Option 2: GitHub Pages (100% Free Forever)
1. Push this repository to GitHub.
2. In your repo on GitHub, go to **Settings** -> **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Within 60 seconds, your site is published at `https://code-by-adi7.github.io/<repo-name>/`.

### Option 3: Netlify (Drag & Drop in 10 Seconds)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this folder directly into the browser window.
3. Your site is instantly live with a free URL!
